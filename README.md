## How I work

1. **Design the system first.** Type, color and components before screens, so every page reads as one product.
2. **Build it for real.** The product screens are working prototypes, not pictures: forms validate, prices add up, state carries between pages.
3. **Prove it with tests.** Playwright checks every page and flow, axe-core checks accessibility (WCAG 2.1 AA), and pytest covers the Python tooling behind the assets.
4. **Ship only on green.** GitHub Actions runs the suites on every push; a failing test blocks the deploy.
